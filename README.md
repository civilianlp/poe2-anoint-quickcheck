# PoE2 Anoint Quick-Check 

Simple tool for Path of Exile 2 campaign speedrunners.

- Click distilled emotions you’ve dropped
- Instantly see craftable amulet anoints
- Template Regex for popular searches (to be expanded)
- Atlas passive icons for quick recognition

Live site:
https://civilianlp.github.io/poe2-anoint-quickcheck/

Data sourced from poe2db.
